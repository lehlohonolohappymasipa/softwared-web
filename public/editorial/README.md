# Editorial images

Drop the selected editorial images in this folder.

Expected filenames (used by the homepage):

- `craft.jpg`  engineering craft / real work
- `collaboration.jpg`  human collaboration / mapping the workflow

Notes:

- Use `.jpg` or `.webp`.
- Keep files reasonably sized (aim ~200600KB each, max ~1.2MB).
- Keep the original aspect ratio; the layout reserves space via explicit `width`/`height`.
