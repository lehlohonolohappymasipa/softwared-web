# softwared — brand language rules

softwared is a long-term product brand. The site should read like a calm, well-designed system.

## Sentence style

- Prefer short, direct sentences.
- Use concrete nouns: system, workflow, bottleneck, dashboard, handoff.
- Describe outcomes over features.
- Make one claim per sentence.
- Use “we” sparingly; use it when it clarifies responsibility.

**Pattern**

- Problem → system → outcome

Examples:

- “We map the workflow. Then we build the smallest version that removes a bottleneck.”
- “A system that replaces spreadsheets and manual admin.”

## Heading style

- Headings should sound like systems, not slogans.
- Use grounded language: clarity, reliability, scope, delivery, foundations.
- Avoid hype words and vague abstractions.

**Good**

- “Custom software development for clearer operations.”
- “Clarity first. Then a steady build.”

**Avoid**

- “Scale faster.”
- “Unlock growth.”
- “Revolutionize your business.”

## CTA tone

Primary CTA (locked): **Book a call**

- Treat it as an invitation to think together.
- No urgency, no pressure language.
- Support with reassurance, not persuasion.

**Good supporting microcopy**

- “We’ll map one workflow and outline a clear first step.”
- “No pressure. If we’re not a fit, you’ll still leave with a clearer plan.”

## How we talk about agents

When we say “agents”, we mean software that executes steps in a workflow— not just an app that stores data and shows dashboards.

- Prefer concrete phrasing: “execution agents”, “workflow agents”, “agents that do the steps”.
- Explain the action: create/update records, send messages, schedule jobs, trigger follow-ups, keep systems in sync.
- Avoid anthropomorphic language (no “the agent thinks/feels/decides”); keep it grounded in guardrails and inputs.
- Always mention control and traceability when relevant: approvals for exceptions, audit trail, clear status.

**Pattern**

- Interface (humans) + agent (execution) + logs (trust)

## Words to avoid → preferred language

- “Affordable” → “lean”, “efficient”, “senior execution”
- “Cutting-edge” → “reliable”, “stable”, “proven”
- “Game-changing” → “measurable”, “practical”
- “Revolutionary” → “well-designed”, “careful”
- “Disrupt” → “simplify”, “replace”, “reduce”
- “Hustle”, “grind” → “steady”, “calm”, “focused”

## What to repeat (intentionally)

- Systems over chaos
- Workflows over features
- Reliability over hype
- Direct collaboration
- Calm scaling
